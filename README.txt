PROYECTO REMATES RECUPERADO

1. Descomprime esta carpeta.
2. Abre la carpeta remates-web-recuperado en VS Code.
3. En Terminal ejecuta: npm install
4. Luego ejecuta: npm run dev
5. Abre http://localhost:3000

Incluye el avance recuperado del chat: portada, productos, buscador, categorías, carrito compartido y pedido por WhatsApp.
